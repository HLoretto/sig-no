# SIGNO-07 · Requisitos funcionales RF01–RF07

**Fase:** Elaboración  
**Hito:** M2 Arquitectura del ciclo de vida  
**Agente:** analista  
**Revisa:** Augusta López  
**Fuente:** Informe de Ingeniería de Requisitos y Modelado, sección 3 (especificación de requisitos técnicos).

| ID | Momento | Regla |
| --- | --- | --- |
| RF01 | Andén | Proveedor y kilos; estado «En cuarentena» en menos de 1,5 s |
| RF02 | Identidad | Código AAAA-MM-NNNN, único y no editable |
| RF03 | Laboratorio | Brix y pH vinculados al lote, con firma del analista |
| RF04 | Dictamen | Liberado si el pH está entre 2,5 y 4,6; bloqueado fuera |
| RF05 | Cava | Ubicación y vencimiento; stock actualizado en menos de 1 s |
| RF06 | Despacho | FEFO: sale primero el lote apto que vence antes |
| RF07 | Trazabilidad | Del cliente al proveedor en menos de 2 s |
